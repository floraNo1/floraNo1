# Yufeng Liang

I am a prospective PhD applicant interested in building **reliable AI agents that can maintain useful state and adapt their decisions over long-running interactions**.

My current interests include **agent memory, long-running agents, reliable AI systems, and knowledge-grounded reasoning**, with a particular focus on how persistent memory and changing state should influence downstream planning and action.

## Current research

### TYDE — Selective State Updates for Long-Horizon Agents

TYDE studies a compact but important question:

> When an agent receives new information, what should be remembered, how should existing state be updated, and when should that change the agent's next action?

The prototype separates current state, scheduled state, project-scoped memory, and downstream planning. Its update decisions are inspectable, and the repository includes executable diagnostic cases, tests, and continuous integration.

**[Code and reproduction instructions →](https://github.com/floraNo1/tyde-research-prototype)**
